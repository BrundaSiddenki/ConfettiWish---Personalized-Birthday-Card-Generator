# ConfettiWish---Personalized-Birthday-Card-Generator
ConfettiWish is a fun web app to create personalized birthday wishes with a clean UI and animated confetti. Built using HTML, CSS, and JavaScript, it showcases skills in DOM manipulation, event handling, and design—perfect for frontend learning and portfolios.
This is a fun and interactive web application . The app allows users to generate a personalized birthday wish card with confetti animations.

🛠 Built With:

HTML for structure

CSS for styling and layout

JavaScript for functionality, user input handling, and confetti animation 🎉

✨ Features:

Input fields for name and birthday message

Live generation of a birthday card

Colorful falling confetti animation using JavaScript

User-friendly, responsive design

🔗 Perfect for showcasing DOM manipulation, styling, and event-driven programming in JavaScript.
